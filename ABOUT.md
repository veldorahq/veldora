# About Veldora

**Veldora** is a modern, developer-first PHP framework engineered for speed, visual excellence, and complete developer ownership.

---

## ✦ The Vision

PHP is one of the most productive languages in the world, powering the vast majority of the web. However, modern full-stack development often feels locked behind heavy vendor packages, bloated admin generators, and complex build steps.

Veldora was created with a simple yet uncompromising philosophy:
> **"A PHP framework you actually own."**

---

## ✦ Core Principles

1. **Zero Configuration, Zero Barriers**: A newly initialized Veldora application runs immediately with zero required dependencies or Composer setup, powered by our self-contained PSR-4 autoloader.
2. **Component Ownership**: When you add a UI component via `php veldora add button`, the raw, customizable code lands in your `resources/views/components/` directory. You own it completely.
3. **Beautiful by Default**: Dark mode first, polished typography, subtle micro-interactions, and Laravel/Ignition-grade developer exception screens.
4. **Built-in Power**: 41 first-party CLI commands for code generation, database migrations, health diagnostics, routing, and deployment optimization.

---

## ✦ Ecosystem Overview

The Veldora ecosystem is split into focused, modular packages:

- **[Veldora Core](https://github.com/veldorahq/veldora)**: Application container, HTTP routing pipeline, query builder, and template compiler.
- **[create-veldora-app](https://github.com/veldorahq/create-veldora-app)**: Fast project scaffolder available via `npx create-veldora-app`.
- **[Veldora UI](https://github.com/veldorahq/veldora-ui)**: 39 pre-styled, accessible UI components with zero runtime JS required.
- **[Veldora VS Code](https://github.com/veldorahq/veldora-vscode)**: Official IDE extension featuring syntax highlighting, IntelliSense snippets, and built-in file icons.
- **[Documentation](https://github.com/veldorahq/docs)**: Live interactive documentation website and component previewer at [veldora.modrao.com](https://veldora.modrao.com).
